# MVP vs Enterprise-Scale Version: MXit 2.0

## 1. Messaging & Communities
| Feature | MVP (Day 1) | Enterprise Scale (Year 2) |
| :--- | :--- | :--- |
| **1-on-1 Chat** | Text, Emojis, basic Voice Notes | E2EE, AI Translation, Scheduled Messages |
| **Groups** | Max 1000 users, basic admin roles | Unlimited users, Threading, Stage Channels |
| **Chat Rooms** | Regional public rooms, manual mods | AI Moderated, Subscription-gated rooms |

## 2. Wallet & Financials (Masheleni 2.0)
| Feature | MVP (Day 1) | Enterprise Scale (Year 2) |
| :--- | :--- | :--- |
| **Custody** | Platform-custodial only | User-choice (Self vs Platform custodial) |
| **Payments** | P2P transfers, simple QR codes | Bill payments, Escrow, Virtual Debit Cards |
| **Integration** | Manual cash-in via bank transfer | Instant cash-in via Mobile Money APIs |

## 3. Mini-App & Ecosystem
| Feature | MVP (Day 1) | Enterprise Scale (Year 2) |
| :--- | :--- | :--- |
| **Mini-Apps** | 2-3 1st party apps (e.g., Arcade) | Open SDK, hundreds of 3rd party apps |
| **Gaming** | Basic trivia, turn-based chat games | Full MoonBase 2.0 MMO, Unity WebGL support |
| **Business** | Basic verified accounts | Full CRM, AI chatbots, Native Ads platform |

## 4. Architecture & Infrastructure
| Feature | MVP (Day 1) | Enterprise Scale (Year 2) |
| :--- | :--- | :--- |
| **Databases** | Single AWS region (af-south-1), RDS | Multi-region, ScyllaDB cluster for messages |
| **AI Models** | API calls to OpenAI/Anthropic | Self-hosted Llama 3 models on GPU clusters |
| **Scale Target**| 100,000 Concurrent Users | 10,000,000 Concurrent Users |
