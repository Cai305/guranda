# UX/UI Wireframes: MXit 2.0 (Textual Descriptions)

## 1. Global Navigation (Bottom Tab Bar)
- **Chat**: Primary messaging hub (1-on-1, groups, channels).
- **Explore**: Chat rooms, public communities, and social feed.
- **Wallet**: Masheleni 2.0 financial dashboard.
- **Hub (Mini-Apps)**: App store for mobility, food, commerce, and games.
- **Profile**: Settings, identity, and social graph.

## 2. Onboarding & Registration Flow
- **Screen 1 (Splash)**: Vibrant, fast-loading MXit 2.0 logo.
- **Screen 2 (Auth)**: Phone number / Email login. OTP verification.
- **Screen 3 (Profile Setup)**: Avatar upload, nickname selection.
- **Screen 4 (Wallet Custody)**: 
  - *Option A*: "Platform Managed" (Easy, secure, password recovery).
  - *Option B*: "Self-Custodial" (You own the keys, advanced users, requires seed phrase backup).

## 3. Chat Interface
- **List View**: Unified inbox. Avatars with online status dots. AI-categorized tabs (Personal, Work, Unread).
- **Conversation View**:
  - Header: Contact name, last seen, call buttons (voice/video).
  - Body: Chat bubbles. Swiping left reveals timestamps.
  - Input: Text field, emoji/sticker picker, voice note hold-to-record, "+" button for attachments.
  - *AI Feature*: A small "Sparkle" icon next to input for AI translation/tone rewriting.

## 4. Wallet Dashboard (Masheleni 2.0)
- **Top Section**: Total Balance (ZAR equivalent). Big "Send", "Request", and "Scan QR" action buttons.
- **Middle Section**: Quick actions (Buy Airtime, Pay Electricity, Savings Pockets).
- **Bottom Section**: Recent transactions feed with icons indicating payment type.

## 5. Mini-App Hub
- **Header**: Search bar ("Search apps, games, services").
- **Carousel**: Featured/Trending Mini-Apps.
- **Grid Categories**:
  - *Games* (Arcade, MoonBase)
  - *Daily Services* (Ride, Food)
  - *Finance* (Micro-loans, Insurance)
- **Launch State**: Tapping an app opens a fast-loading bottom sheet or full-screen webview with native transition.

## 6. MultiMX / Community View
- **Left Sidebar (Drawer)**: List of channels (e.g., #announcements, #general, 🔊 Voice Lounge).
- **Main View**: Discord-like chat thread. Pinned messages at the top.
- **Right Sidebar**: Member list categorized by roles (Admin, Mod, Online).

## 7. AI Assistant View
- **Access**: Floating action button or dedicated "MXit AI" chat in the inbox.
- **Interface**: Chat-based interface with quick suggestion chips ("Summarize my unread messages", "Find a cheap flight", "Translate this phrase").
